
# Student Portfolio Website

## About the Project
This project is a personal portfolio webpage for a Software Engineering student with an interest in programming and graphic design.

The webpage introduces the student, highlights technical and creative skills, showcases project examples, and provides a contact section.

## Technologies Used
- HTML5 for webpage structure
- CSS3 for styling and responsive design
- Git for version control
- GitHub for hosting the project repository

## AI Tool Used
ChatGPT was used to help generate the initial HTML webpage and suggest improvements during development.

## How AI Helped
AI helped organize the webpage into clear sections, improve the visual design, create project cards, and add responsive CSS for different screen sizes. It also helped explain Git commands and the process of tracking changes through commits.

## Features
- Personal introduction
- Skills section
- Featured project cards
- Contact section
- Responsive layout for mobile and desktop screens
- Version history tracked with Git

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
