# Student Portfolio Website

A simple personal portfolio webpage for a Software Engineering student and graphics designer.

## AI Tool
ChatGPT was used to help generate the initial HTML structure and suggest improvements to the webpage.

## How AI Helped
AI helped organize the page into clear sections, including About Me, Skills, Projects, and Contact. The page will be improved in stages with styling, responsiveness, and small interactive features.

## How to Run
Open `index.html` in a web browser.
